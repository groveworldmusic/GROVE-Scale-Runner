# Arpeggiator Specification

## Purpose

A destructive tool that generates a sequence of new MIDI notes (an arpeggio) based on the current selection of notes.

## Requirements

### Requirement: Arp Tool Operation

The system SHALL implement an "Arp" tool, triggered by the shortcut **'A'** (char 65).

When activated, the tool SHALL:
1. Identify all notes in `selected_indices`.
2. Sort their pitches in ascending order.
3. Generate a new sequence of notes based on the following parameters:
   - **Direction**: `Up` (C-E-G), `Down` (G-E-C), `UpDown` (C-E-G-E), `Random`.
   - **Speed**: The interval between notes in the sequence (e.g., 1/8, 1/16, 1/32 beats).
   - **Pattern**: `Sustain` (notes overlap) or `Staccato` (notes are short, non-overlapping).
4. Insert the generated notes into the `piano-roll-store`.

#### Scenario: Arp Up 1/16

- GIVEN selected notes forming a C Major chord (C4, E4, G4) at beat 1.0
- WHEN user presses 'A' with settings (Direction=Up, Speed=1/16, Pattern=Staccato)
- THEN 3 new notes are created:
  - C4 at beat 1.0
  - E4 at beat 1.0625
  - G4 at beat 1.125
- AND the original chord notes remain (destructive addition)

#### Scenario: Arp Down 1/8

- GIVEN selected notes (C4, E4, G4) at beat 1.0
- WHEN user presses 'A' with settings (Direction=Down, Speed=1/8)
- THEN new notes are created in order: G4, E4, C4 with 0.125 beat spacing

### Requirement: Arpeggiator Undo

The entire arpeggio sequence generated by a single 'A' press SHALL be captured in a single undo entry of type `"add"`.

#### Scenario: Undo arpeggio

- GIVEN an arpeggio of 8 notes was generated
- WHEN user presses Ctrl+Z
- THEN all 8 generated notes are removed from the store in one operation
- AND the original selection is restored
