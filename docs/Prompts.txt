Vamos a lanzar una exploración para preparar el proyecto para que otros modelos LLM puedan trabajar comodamente con el y continuar desarrollandolo para eso vamos a establecer todos los AGENTS.md necesarios en cada ruta orquestados por el AGENTS.md root.
Quiero tener siempre un orden profesional en la raíz de mi proyecto, no quiero que los modelos LLM creen archivos de documentación o de cualquiero otro tipo de manera desorganizada si no que tengan ya definido una estructrua para lograr esto. Necesito tener un AGENTS.md (root) que se ecarga de cordinar una serie de AGENTS.md (hijos) que son agentes específicos para cada seción de el software y el proyecto el agente root maneja los agentes hijos y de esta manera tenemos una estructura profesional y escalable y unos estándares siempre listos para que los modelos LLM puedan trabajar de manera eficiente y organizada.
Vamos a habilitar los test del proyecto, para poder estar seguro que lo que vamos implementando va funcionando correctamente.
Quiero que mis modelos LLM actualicen los AGENTS.md automáticamente cuando haya algún cambio relevante o un aprendizaje nuevo de un error, bug o solución, alguna desición tecnica o de otro tipo, que cree uno o varios archivos con toda esta iformación y que en el AGENT.md lo referencie claramente para que lo modelos puedan usarlo para no cometer errores y poder recordar estas desiciones, que utilice engram también para guardar y recupera informació.
